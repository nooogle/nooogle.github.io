# Previews

Copies of work in progress, for trying on a phone before it's merged into the real app.
Each one goes in a folder named after its branch (a new address each time, so phones don't show an old copy).
They're not linked from anywhere, keep their own separate progress, and get deleted once the work is merged.

- `preview/practise-feedback/` is the `practise-feedback` branch (Practise replays the strokes, then fades them; the button becomes Clear)
